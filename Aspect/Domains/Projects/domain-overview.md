# Projects (dom.projects)

## Summary
Manages overall project metadata and high-level organization of work.
Defines projects that bundle modules, issues, and cycles.

## Users
- Product owners and project managers: create and organize projects.
- Team members: see project context and participate in planning.

## Core Capabilities
- Creating and updating project details.
- Organizing modules, cycles, and issues within projects.
- Managing project timelines and objectives.

## Key Pages & Entry Points
- `/projects`, `/project/[id]`
- API routes `/api/projects/*`

## Representative Code
- Project management UI and backend services.

## Related Entities
`Project`, `Module`, `Cycle`, `Issue`

## Dependencies
- Foundation for Modules, Cycles, and Issues domains.

## Product & Business Value
Central to project governance and coordination.

## Review Notes
Potential overlap in timelines with Cycles; consider integration points.
