# Views (dom.views)

## Summary
Allows users to customize the presentation of issues and projects with filters and saved configurations.
Facilitates workflow personalization and focused tracking.

## Users
- Team members: create and apply filters to view relevant tasks.
- Project managers: define views that highlight key metrics.

## Core Capabilities
- Creating, saving, and sharing filtered views.
- Filtering issues by properties and status.
- Customizing dashboards and lists.

## Key Pages & Entry Points
- `/views`, `/view/[id]`
- API routes `/api/views/*`

## Representative Code
- View components in frontend UI and API backends.

## Related Entities
`View`, `Filter`, `User`

## Dependencies
- Depends on Issues and Projects domains.

## Product & Business Value
Enhances user productivity and insight.
